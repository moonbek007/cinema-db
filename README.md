Front-end of [Cinema DB](https://moonbek007-api-cinema-db.netlify.app/api/).

---

## ✨ Features

- **Core Feature:** Visualizes database data about movies and shows using modern UI components.
- **Performance:** Optimized performance and SEO through prefetching server data, fast data fetching for pagination and searching.
- **User Friendly:** Responsive design and straightforward UI.

## 🛠️ Tech Stack

- **Frontend:** TypeScript, React, Next.js, Tanstack/React-Query, Tailwindcss, Sass
- **Database:** MongoDB, Redis
- **Tools:** Git, Netlify, TVMaze API
